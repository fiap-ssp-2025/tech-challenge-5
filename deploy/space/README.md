# Guardiã AI

Apoio à análise inicial de atendimentos de mulheres em situação de violência: ficha preenchida a partir do relato
(texto ou voz), modelo de encaminhamento à rede de proteção com SHAP, protocolos citados (RAG) e nota de apoio
auditada por um segundo modelo. A decisão é sempre da profissional. Nenhum nome ou documento é necessário; o relato
nunca é armazenado (só o hash).

Código, dados, notebooks e relatório: https://github.com/fiap-ssp-2025/tech-challenge-5 ·
Tech Challenge 5 · FIAP Pós-Tech IA para Devs · grupo fiap-ssp-2025.
